# 方块操作机构程序设计简介（汇报版）

## 1. 目标

这套程序负责让机器人完成大地块的侧吸取块和放块。

第一版的基本思路是：

```text
机械臂自动到方块附近的粗定位姿态
→ 操作手用底盘完成最后的靠近和对准
→ 操作手确认吸附或释放
→ 机械臂自动撤回安全姿态
```

这样第一版不要求机械臂自动完成最后几毫米的精确对准，优先保证流程清晰、能调试、能实际操作。

## 2. 程序分层

```text
PickBlockTask / PlaceBlockTask
        ↓
BlockArm + BlockVacuum
        ↓
Motor
        ↓
DJI 电调 / ZDrive 电调
```

| 模块 | 负责什么 | 不负责什么 |
|---|---|---|
| Task | 按顺序组织“移动、等待、吸附/释放、撤离” | 直接控制电机角度或真空硬件 |
| BlockArm | 两个耦合电机共同控制连杆机械臂，归零、粗定位、撤回安全姿态 | 比赛任务的完整流程 |
| BlockVacuum | 吸附、保持、释放及状态确认 | 机械臂运动 |
| Motor | 给单个电机发送位置/速度命令，读取反馈 | 判断机械臂是否完成归零 |

## 3. 取块流程

```text
启动低位/高位取块
→ 机械臂到对应粗定位姿态
→ 等待操作手完成最终对准
→ 确认吸附
→ 等待真空确认吸住
→ 机械臂回到安全姿态
→ 取块完成
```

取块 Task 的状态为：

```text
IDLE
→ MOVE_TO_PICK_PREPARE
→ MANUAL_ALIGN
→ GRAB
→ MOVE_TO_SAFE
→ DONE
```

其中 `MANUAL_ALIGN` 的意思是“最终对准等待区”，并不强制要求机械臂微调。

## 4. 放块流程

```text
启动底层 / 第一层 / 第二层放块
→ 机械臂到对应高度的粗定位姿态
→ 等待操作手完成最终对准
→ 确认释放
→ 等待真空确认释放
→ 机械臂回到安全姿态
→ 放块完成
```

放块 Task 的状态为：

```text
IDLE
→ MOVE_TO_PLACE_PREPARE
→ MANUAL_ALIGN
→ RELEASE
→ MOVE_TO_SAFE
→ DONE
```

## 5. 第一版的最终对准方案：由底盘完成

当前建议作为第一版主方案：

```text
机械臂保持粗定位姿态
→ 操作手低速控制底盘靠近或后退
→ 侧吸盘贴住方块侧面 / 方块获得下方支撑
→ 操作手按确认键吸附或释放
```

优点：

- 不需要先解决复杂的双电机微调轨迹；
- 现有 Task 和 Mechanism 框架可以直接使用；
- 程序实现和现场调试都更简单。

需要注意：机械臂伸出后，底盘应低速靠近，避免碰撞、推动方块或使方块偏移。

## 6. 后期可选项：机械臂四方向微调

如果后期发现底盘最终定位不够方便，可以在不推翻当前框架的前提下增加机械臂微调。

操作手表达的是末端运动方向：

```text
前 / 后 / 上 / 下
```

`BlockArm` 内部再根据当前姿态，让两个耦合电机按合适的组合方向和速度运动。

```text
操作手按住“向前微调”
→ BlockArm 协调两个电机
→ 吸盘末端小范围向前移动

操作手松开按键
→ BlockArm 停止微调并保持当前位置
```

这项功能的价值是降低底盘最终停车精度的要求；但它需要机械分析或实物标定，确认两个电机组合后末端的实际运动方向。因此它是后期优化项，不是第一版必须条件。

无论是否启用微调，Task 中的 `MANUAL_ALIGN` 状态都保留：

```text
第一版：等待底盘完成最终对准
后续版本：等待机械臂微调或底盘对准完成
```

## 7. 机械臂归零与安全姿态

每次上电后，机械臂原始位置不可靠，必须先执行归零，建立固定参考系：

```text
BlockArm_Home()
→ 两个电机按机械验证的顺序低速寻找收位参考
→ 记录两个电机当前位置为零点
→ 保持收位姿态
→ BlockArm = READY
```

最终推荐使用机械挡块配合限位传感器。若暂时没有限位传感器，可临时使用“低速顶到挡块、位置长时间基本不变”的堵转式归零，但可靠性更低，必须增加超时保护。

安全姿态 `Safe` 是两个电机共同保持的一组位置目标。到达 `REACHED` 只表示“已经到位”，不表示关闭电机；电机仍应保持位置模式，防止机械臂因重力下落。

## 8. 当前已经搭好的程序框架

```text
Task/
├─ PickBlockTask：取块流程状态机
└─ PlaceBlockTask：放块流程状态机

Mechanism/
├─ BlockArm：双电机机械臂状态、粗定位、归零、Safe、预留微调
└─ BlockVacuum：真空吸附和释放状态
```

框架已经使用 `enum + switch-case + 非阻塞 Process()` 实现。当前尚待实机补充的主要是：

```text
两个电机的归零方向、限位方案和顺序
各个粗定位姿态对应的双电机位置目标
到位判据
真空吸附/释放的实际硬件控制与确认判据
（可选）四方向机械臂微调参数
```

## 9. 结论

第一版不依赖机械臂微调即可运行：

```text
自动粗定位 + 底盘最终对准 + 人工确认吸附/释放 + 自动撤离
```

后续若比赛操作中发现底盘对准要求过高，再把四方向机械臂微调作为增强功能接入；现有 Task / Mechanism 框架无需推翻。
